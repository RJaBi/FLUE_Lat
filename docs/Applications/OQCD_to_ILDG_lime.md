# OQCD_to_ILDG

Reads an openqcd format gaugefield. Writes it to ILDG-lime format.

The ILDG-lime format is the [LIME](https://usqcd-software.github.io/c-lime/lime_1p2.pdf) container of the ILDG-ordered big-endian gaugefield


Run using


```
fpm run OQCD_to_ILDG_lime -- inputFile outputFile NT NS
```
